# `_reverify` — перепроверка фазы 0 верным протоколом (2026-09-06)

Четыре числа `CANNOT-AFFORD` в отчёте фазы 0 были сняты **в одном процессе**:
`cost-ab.ts` соседних семейств чередует армы по раундам, а не процессы, и
`pending-shell/cost.ts` гоняет mitata. Для sub-ms A/B это невалидно —
вторая копия в одном процессе платит ×2.7.

Здесь протокол верный: **одна арма на процесс**, чередование процессов,
медиана по раундам, свой пол A/A той же командой.

⚠ И у двух исходных проб был изъян сверх протокола: армы A и B держали **два
разных объекта в одном процессе** (два роутера с разными кодеками; два
замыкания `getState`), из-за чего сайт вызова становился полиморфным. Здесь
каждый процесс строит один объект, и сайт остаётся мономорфным.

## Запуск

```bash
cd benchmarks
ARM_FILE=<арма>.ts node audit-probes/membrane-globality-2026-09-05/_reverify/drive.mjs <X>:<Y> <итераций> <раундов>
```

`drive.mjs` без `ARM_FILE` берёт `pending-shell-arm.ts`. Первым делом всегда
меряется пол `A:A` — числом, а не предположением.

снято с ГЛУБОКОЙ (контейнер и оба листа); канон (а) — только контейнер, листья
по ссылке — это арма `S`.

## `control3-search-params.ts`

Третья контрольная рука. Правило отбора объявлено до замера: экспортируемые
функции `engine/search-params`, чьи параметры допускают объект вызывающего.
Взята потому, что `utils/fsm` и `utils/logger` **структурно не способны**
предъявить P1 — в них нет контейнера вызывающего перед горлом, и их «1 из 17»
поэтому не база, а пустая клетка.

Результат: `makeOptions` спрашивает `opts.arrayFormat` в гварде раннего возврата
и берёт его снова в присваивании — два чтения, садится дрейфнувшее значение
(`index` вместо `brackets`). `build(params)` на той же области читает ключ один
раз. Позитивный контроль чист.

⇒ Клейм «дефекты P1 специфичны для мембраны» снят: это тот же ask-then-take,
регенерирующий везде, где мешок читают по имени.

## Позитивные контроли

Каждая арма проверяет себя изнутри и выходит с кодом 2, если контроль не прошёл:
запись конфига непуста · матч состоялся и параметр на месте · гейт вернул булев.
